## Summary

The Firm invites Ryan to the build-challenge round of its federal FDE hiring process, after a
recruiter screen (2026-10-20) and a positive technical screen (feedback 2026-10-29). Ryan must
build an agentic system using Claude, Gemini, or GPT within one week, then present it in a
60-minute interview: a 15-minute presentation that is mostly live demo, code walkthrough, and
architecture review; a 30-minute deep dive; and 15 minutes of standard technical and behavioral
questions. Ryan replied the same day acknowledging receipt.

## Key claims

- The system "does not have to be production-ready by any means" but needs "sufficient
  complexity (e.g.: orchestration of multiple agents, setting up an MCP Server and/or Client,
  accessing data via APIs, building skills, etc)."
- The presentation must cover "why you chose your problem, who your users are, and the impact you
  expect," plus "technical choices," "system architecture," and "how you're using your LLM of
  choice." Slides are optional and only for the problem statement.
- Deadline: notify the recruiter on completion, no later than EOD 2026-11-05.
- The challenge is run by the Firm's federal FDE program (see
  [entity page](../entities/firm-federal-fde-program.md)).

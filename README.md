# fde-interview

Research and design workspace for a forward-deployed engineering interview project.

Research lives in [`wiki/`](wiki/index.md), an LLM-maintained knowledge base built on
Andrej Karpathy's [LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f)
pattern. The agent's workflow is in [AGENTS.md](AGENTS.md). Raw sources stay local
(gitignored), and the wiki cites them.

Can Ryan pick up Databricks fast? Fast enough to spend $517 of it in one afternoon, then move the whole platform off it before midnight.

Round one asked whether Ryan can pick up Databricks fast. This is the postmortem. Three days from signup to a governed semantic layer, Genie, and a managed MCP endpoint the agent called 4,800 times. Then the bill for calling it. The card was charged about $100 past the $400 of trial credits. Everything the agent learned survived the move. The budget did not.

Root cause: five findings, no villains, one owner

FindingStatus
The SKU check was never closed. Spec 01 said to confirm on day one what the managed MCP function server bills to. It was still "Open, due 2026-11-01" when the climb started. The estimate assumed 75 runs; the climb ran 1,720.Root cause
The cost tracker measured the wrong thing. The harness's cost field counts model tokens, which came to $2.68. Compute was billed elsewhere, at 150 times that.Contributing
Adding a card removed the cap. It went on to lift an egress block. It did not lift the block. It did convert the trial from "stops at $400" to "sends an email at $400."Contributing
The budget alerts were real and useless. $25 and $45 thresholds, email only, at list price, with up to 24 hours of lag. The afternoon was over before the lag was.Contributing
Genie as a service principal is a billable product. Called from the agent rather than by a person, it bills real-time inference per request. Fine at demo volume, not at eval volume.Contributing

Corrective actions. Platform torn down the same evening and the account emptied the next morning. A guard grep in the repo's instructions fails any commit that could reach the workspace again. The harness's cost field still counts model tokens, and on Postgres that is the whole bill: nothing else is metered per call. The $50 budget is enforced by the cheapest instance class on RDS and nothing serverless per call.

What survived the moveunchanged, byte for byte, from the Databricks era

Unchanged

The eval set (eval-v1). All 1,720 graded rows. The prompt and skills, one hash apart. The harness and its fourteen scorers. The demo app and the tester app. The source files on disk.

Re-expressed

The same eight views and eight functions, same signatures, same return columns, behind a read-only role with a 60-second statement timeout. The imputation hash moved from xxhash64 to md5: same design, different bits, two truth rows re-pinned, sixteen reproduced.

Lost

Genie, replaced by a fenced SQL tool over the same views. The AgentCore gateway that was going to sit in front of the MCP endpoints, never built. The Unity Catalog governance story, now told as a Postgres role with grants, which is the same story with fewer logos.

Gained

Median latency 10 s where Genie took 44. Zero per-call cost, so the agent can fan out as much as it likes. A $14-a-month data layer with one public address in its security group.

Severity assessment

Customer impact: none, there were no customers. Data loss: none, the data is public and monthly. Budget: exceeded ten times over at list. Lesson retention: high. Ryan still has the email.

Three days to learn the platform well enough to build a governed semantic layer on it. One afternoon to learn its pricing. One evening to leave. Can Ryan pick up Databricks fast? The bill says yes.
